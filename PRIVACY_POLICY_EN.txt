1. SCOPE AND CONTACT
This policy concerns the MiaDock 2 application. The Developer and data controller for processing under his responsibility is Eray Durupınar (mymiamo.net), Türkiye. Privacy inquiries: info@mymiamo.net. Microsoft Store, external websites and services may be separately responsible for their processing activities.

2. LOCAL OPERATION
MiaDock 2 does not require a separate user account or automatically send telemetry, usage statistics or crash reports to the Developer. User settings and error logs are stored on the device and are not synchronized to a Developer cloud. To provide media, audio, customization and system controls, the application may locally process media title, artist, album, playback duration, audio and volume, running applications and shortcuts, display and system status, Wi-Fi, Bluetooth, battery and brightness information. Windows GSMTC, WASAPI/NAudio and Windows system APIs are used. Whisper.net audio analysis and timing validation and Spleeter/ONNX Runtime source separation run locally. Audio recordings for this analysis are not sent to the Developer or a remote AI service. Local error logs are not automatically transmitted externally.

3. ONLINE FUNCTIONS AND RECIPIENTS
Local operation does not mean absence of all network traffic. The following connections support application functionality:
• Lyrics: LRCLIB (https://lrclib.net/docs), LRCMux (https://lrcmux.dev/) and lrc.red (https://lrc.red/api). Track title, artist and, where needed, album and duration are sent. Requests use no API key and include the Developer contact email in the User-Agent header. Providers may see the connection IP address and standard HTTP request information; LRCMux may forward queries to other lyrics sources. The purpose is to find and display matching lyrics. Track metadata may reveal listening preferences.
• Model download: the Spleeter model is downloaded at installation from GitHub sherpa-onnx releases (https://github.com/k2-fsa/sherpa-onnx/releases/tag/source-separation-models). Connection and request information may reach the download source; local audio analysis itself is not sent to a server.
• Licensing and purchases: Microsoft Store handles account, purchase, device entitlement and license validation operations. Microsoft's own account and transaction information is covered by its privacy statement: https://privacy.microsoft.com/privacystatement. There is no separate Developer account or license server.
• Update checks, online icon/theme downloads and weather: when enabled, these functions connect to the relevant provider and may transmit necessary request information. Icon, theme and weather providers and exact request fields have not yet been confirmed; this section must be completed before publication. If weather uses location, its source, precision and recipient must be separately disclosed.
• Web and support links: when opened, the browser and destination website apply their own connection and data processing terms. This policy does not cover all processing by the Developer website.
Third-party retention periods, server locations and onward transfers are outside the Developer's direct control. The absence of automatic Developer telemetry does not mean these services do not process data.
